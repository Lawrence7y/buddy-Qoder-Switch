## 🔗 改名收尾：自动更新与下载地址全部指向新仓库

仓库已迁到 `NextAgentX/qoder-trae-workbuddy-switch`。上一版只修了 CI 与在线演示，**客户端里写死的旧地址还在** —— 检查更新、下载安装包、README 的下载与 Issue 入口，全都指回改名前的仓库。旧地址目前靠 GitHub 的重定向还能打开，但这条兜底不属于我们的可控项：一旦重定向策略变化，用户看到的就是「已是最新」或是 404。

- **自动更新地址（本次唯一的功能性改动）**：客户端与服务端的仓库坐标、Tauri updater 的三个端点、更新清单生成脚本的默认坐标，全部改为新仓库。改名后没跟着改，自更新会在无人察觉的情况下静默失效。
- **下载与反馈入口**：8 个语种 README 的版本/Stars 徽章、Releases 链接、新建 Issue 链接、Star 历史曲线，以及 CONTRIBUTING、LICENSE 版权声明行、npm 包说明、许可说明，统一换到新地址。
- **保留旧名的地方**：几处代码注释与历史文档记的是「改名前的演示 base 路径」这一事实（`vite.config.ts`、`check-pages-base.cjs`、`docs/history/`），按原文保留，避免把事故复盘改歪。
