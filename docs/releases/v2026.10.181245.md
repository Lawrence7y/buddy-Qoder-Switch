## 🧭 账号详情抽屉：从「七段长滚动」改成「指标 + 页签」

同一个账号的动作此前散在三处：刷新在菜单、刷新 Token 在抽屉、手动签到两边都能点，删除还埋在抽屉最底部。这一版按一条判据收敛 —— **能一步做完的进菜单；要看数据才敢决定的留在抽屉**。

- **顶部四个指标块**（积分 / 今日 Token / 签到 / 凭据），一打开就知道这个账号现在什么状态，不用往下滚。每块右上角一枚 ⟳，**就地刷新这一项**（与菜单里的四项同一个回调，不是第二套实现）。
- **正文改成页签**：概览 / 积分 / 签到 / 凭据 / 快照（按有无内容出现）。备注、分组、程序位切换**留在页签之上** —— 它们是身份与操作，藏进页签会让「改个备注」变成「先猜在哪个页签里」。
- **「用向导切换」挪到固定底栏**：长列表滚到底才找得到的问题消失。
- 抽屉里的「操作」区只剩三枚抽屉独有的按钮（刷新 Token / 导出 / 权限诊断）；手动签到、编辑备注、编辑分组、删除**只在卡片「更多」里**，删除不再埋在抽屉底部被顺手点到。

## 🔄 卡片「更多」：四类数据各自刷新

四类数据来自不同层，快慢与失败原因都不同，合成一个「刷新」时慢的拖住快的、失败也分不清是哪一层：

- **WorkBuddy**：积分 / 今日 Token / 签到状态 / 凭据状态，四项齐全。
- **Trae / Qoder**：只有「积分 / 凭据状态」两项 —— 它们没有「今日 Token」「签到状态」的**按账号·今日**只读接口。摆一个点了只会重读缓存的菜单项，比不摆更坏。
- 进行中态按「账号 + 项」记：点一项不会四项一起转，多个账号同时刷新也不会互相吞掉。

## 🏷 分组可以新建了

分组在后端是自由文本，之前只有一个输入框 —— 用户看不见「已经有哪些组」，同一个组很容易被打成「客户A / 客户 A / 客户a」三份。现在改成「既有分组列表 + 就地新建」：点开先看到这个作用域里已有的组（含「未分组」），最后一枚是「新建分组」，重名会提示将直接归入。

## 💰 积分 / 资源包明细

抽屉的「积分」页按资源包逐条列出：包名 · 到期时刻 · 剩余/总量 · 已用 · 剩余占比条。三处刻意做对的地方：

- 进度条画的是**剩余占比**（画成已用就成了「条越长越穷」）；
- 颜色按**到期紧迫度**（7 天内橙、否则绿），与卡片徽章同一口径 —— 没动过的包也可能下周就过期，那才是要提醒的事；
- 到期显示到**分钟**（只写「3 天后过期」时，用户判断不了赶不赶上）。

同时修掉两处数据自相矛盾：临期积分改为**从资源包派生**（此前出现过「指标块说无临期积分、积分页却摆着一个快到期的包」）；资源包剩余合计与账号积分精确相等。

## 🗂 快照页签

Trae 的登录态快照进了抽屉（最近修改 / 文件数 / 大小）。打开抽屉时才按账号拉取，不在列表页为一个可能不打开的抽屉预扫全部槽位。

## ⚠️ 已知限制

- Trae / Qoder 的「今日 Token」「签到状态」两项刷新需要后端新增按账号、今日口径的只读接口，已写成约定（`docs/specs/api-trae-qoder-per-account-refresh.md`）并单独跟踪；接口到位后前端只需打开两个开关。
- Qoder 的「今日 Token」不会做：它的计量单位是 credits，没有 token 概念。
