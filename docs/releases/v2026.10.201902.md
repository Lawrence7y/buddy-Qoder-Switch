## 🖥 服务器 / 容器部署：没装客户端也能登录、也能开网关（issue #62）

- 症状：在服务器上部署、本机没装任何平台的客户端时，账号页只给「重新检测 / 从本机导入」两条死路 —— 登录不了，网关也就没有上游账号可用。
- 定位：这不是「缺一个入口」，而是把「没装客户端」当成了异常。账号与网关只依赖**凭据本身**，客户端只负责「现成的登录态来源」与「程序位切换」。
- 现在「无客户端」是一等形态：账号页给引导卡（浏览器授权 / 粘贴凭据 / 导入备份 + 可用与需客户端两列清单），已有账号时只留一行说明。
- 授权弹窗改成「链接 + 二维码 + 倒计时 + 轮询」：容器里没有系统浏览器也能完成，手机扫码或复制链接到任意设备即可；自动开浏览器降级为尽力而为，失败不再算登录失败。
- 新增「粘贴授权凭据」（WorkBuddy）：把另一台机器上 `auth/workbuddy-desktop-ai.info` 的内容整段粘进来即可入库，与「从本机导入」走同一条解析 / 解锁链。
- Trae 例外已如实说明：换 token 与续期都要客户端 `storage.json` 里的 icube 设备私钥，且授权页会探 `127.0.0.1:17388`；弹窗给出可复制的 `ssh -L` 命令，并支持把回调链接粘回来由服务端补完兑换。
- 网关页在无客户端时明确写「网关照常可用」—— 它只依赖账号池里的凭据，与客户端是否同机无关。

## 🧹 设置页新增「清除缓存」

- 只读扫描四类缓存（会话备份 / 登录态快照 / 缓存目录 / 日志）的体积，勾选后按类别清除，返回实际释放的字节数与逐项失败原因。
- 部分失败会如实报「清了但有 N 项失败」，不会一律显示成功；清除前有确认弹窗，属不可逆操作。
