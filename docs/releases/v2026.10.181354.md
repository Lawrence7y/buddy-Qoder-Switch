## 🔄 「更多」菜单按原型重做，表格视图也补上了

账号卡片右上角那个「⋯」此前与设计原型差了不止一处：没有账号名抬头、点一下就关菜单、
签到只有「能点」一种形态、导出入口藏在抽屉里、备注和分组编辑与抽屉重复。

- **抬头 + 结尾提示**：菜单顶部显示账号名，底部提示「备注与登录态在账号详情里（点卡片打开）」——
  备注 / 分组编辑因此从菜单移出（它们在详情抽屉里），提示指路，不再两处重复。
- **点刷新不关菜单**：刷完一项常常紧接着刷下一项；而且「刷新中 / 已更新」这两个状态
  只有菜单里看得见。现在刷新项保持菜单打开，成功后亮 900ms「已更新」。
- **签到改成三态**：已签到 → 灰字「今日已签到」；凭据失效 → 灰字「手动签到 · 需先登录」；
  其余才给可点入口。此前只有「可点」一种，凭据失效的账号点下去必然失败。
- **导出账号**回到菜单；**去掉「查看详情」**（点卡片 / 点行就是打开详情，两个入口做同一件事没必要）。
- **表格视图每一行也有了同一个菜单**：此前只有卡片有，表格里只能点行进详情再找动作。

## 🧾 Trae / Qoder 的刷新项补齐

「刷新」拆成四类后（积分 / 今日 Token / 签到状态 / 凭据状态），Trae、Qoder 此前只有两项。
本期后端补上了**按账号、今日口径**的只读命令（`get_trae_account_token_today`、
`get_trae_checkin_status_map`、`qoder_checkin_status_map`），并把它们接到界面上：

- **Trae 四项齐全**，卡片新增「今日 Token」指标：此前菜单里有这个刷新项，卡片上却没有这个数字，
  刷完只弹一句提示，等于那条入口是假的。现在缺席就显示「—」，网关日志被裁时显示「≥N」。
- **Qoder 三项**（积分 / 签到状态 / 凭据）：刷新签到状态后，卡片上的签到态立刻更新。
- **Qoder 刻意没有「今日 Token」**：它的计量单位是积分（credits）、没有 token 概念，
  摆一个点了只能重读缓存的入口，比不摆更坏。

三条诚实边界仍然成立：读不到 ≠ 没签到、缺席 ≠ 0、被裁的值只是下界。

## 🐛 修复：详情抽屉的页签被压成一条缝

抽屉滚动区是纵向 flex 容器，内容一高，内层的页签容器会被压扁，页签只剩一条 8px 的细缝
（程序位那行下面夹着被切掉的一排）。已修复并复验。
