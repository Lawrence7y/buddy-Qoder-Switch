## ⚠️ 升级前必读：网关端口统一到 `5789x`

四条网关的默认端口收敛到同一段：界面 `57890` · WorkBuddy 网关 `57891` · 统一入口 `57892` · hook `57893` · Trae 网关 `57894` · Qoder 网关 `57895`（Trae / Qoder 原来是 `7864` / `7865`，与 WorkBuddy 混在两段里看不出规律）。

- **只改默认值**：你在 `trae/api_gateway.json` / `qoder/gateway_config.json` 里显式写过 `port` 的，保持原样，客户端也不用动。
- 吃默认值（没写过端口）的：把客户端指向新端口。Qoder 的 Key 前缀同时改为 `sk-qoder-`。

## 🔧 网关：不再「明明有号，却整池 401」

- **在途额度泄漏根治**：请求被取消（客户端断开、超时）时额度一定归还，不会再把整个池卡成「0 个可用」。此前这种状态只能靠重启进程恢复。
- **并发占满改回 `503 pool_busy`**（带 `Retry-After: 2`），不再用误导性的 401：凭据和余额都好着，等两秒重试即可。
- **排不上号时把原因逐项摆出来**：N 个已禁用 / 冷却中 / 余额为 0 / 被你排除 / 在途已满；失败响应还带 `error.attempts`（这一轮换过哪些号、各自为什么不行）。
- **首帧即错误信封**（上游 200 但首帧报错）时改为换号重试，不再白烧一次请求；上游用 CRLF 换行的 SSE 也能正确切帧（用量统计与流内错误恢复正常）。

## 🎛 账号池

- 支持**排除账号**（硬约束：自动选号 / 兜底 / 粘性 / 指定全部跳过），被禁用的账号可一键恢复。
- **模型级限流冷却**：同一账号「对 A 模型冷却、对 B 模型仍可服务」，账号池与限流探测都按模型区分，不再一刀切。
- 「可路由」格里会标出「其中 N 个在途已满」—— 可用 ≠ 此刻跑得动，不用再去猜。

## 🗓 定时任务与其它

- 定时任务时点支持**分钟粒度**，并可开启**随机抖动**（避免整点扎堆触发）。
- Trae：对话复用稳定会话 ID（跨轮不再每次新开）＋ 转发抓取诊断旁路（默认关闭）。
- macOS：修复 at-rest 加密信封账号解锁失败（可执行体名改读 `Info.plist`）。
- README 改为图优先，并新增 6 种语言。
