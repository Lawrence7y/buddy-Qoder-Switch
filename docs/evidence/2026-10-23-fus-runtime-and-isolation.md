## 1. 测试隔离事故与证据更正

上一轮与本轮早期命令将 `BUDDY_SWITCH_HOME` 指向尚未创建的目录。`config::home_dir()` 的原有行为是忽略无效覆盖并回落真实用户目录，因此管理测试实际读写了 `C:/Users/Administrator/.buddy-switch/management.sqlite`。上一轮报告与回复中“隔离验证、未接触真实数据”的表述不成立。本节是对这些表述的显式更正，原报告、日志、manifest 均保留。

已确认的影响包括测试运行记录、一个 `plan-*` 测试规范、测试账号引用、v5 管理 schema 迁移，以及真实用户目录中的一个 `recovery-*.sqlite` 测试文件。快照时管理库有 56 条 run；没有前置快照，不能将全部记录都归因于本次测试，也无法精确自动回滚。本轮管理动作采用离线 handler，不构成真实签到或奖励到账证据。

处置：

- 停止向该目录执行测试；使用 SQLite 只读连接的 backup API 保存完整快照到工作区 `reports/management-before-isolation-repair-20261023.sqlite`。
- 原库与测试文件保留，未删除或尝试不确定的自动回滚。快照包含用户管理数据，仅保留本地。
- 源库/快照的大小与 SHA-256 保存在 `reports/fusion-runtime-20261023-isolation-baseline.json`。更正后测试期间多次比对源库 SHA-256，均与保存的基线相同。
- `management::store::open_db()` 新增已有 home 覆盖护栏：目录不合法时直接报错，不打开回落路径。
- 新增 `scripts/test-management-isolated.ps1`：先创建工作区内的独立目录、核对解析路径，再设置覆盖变量；结束后恢复环境变量。`-Workspace` 执行全仓回归，不加参数执行管理定点测试。新测试验证无效目录直接拒绝且不被创建。

确认现有 BuddySwitch 进程仍为 PID 33496，路径 `D:/buddy-switch/BuddySwitch/buddy-switch-rust.exe`；未停止、重启或替换该进程。这不能抵消上述真实用户管理库写入，二者分别记录。

## 2. 本轮交付

### 排程与两宿主接线

- `background::TaskKind::ManagementRuntime` 注册进统一后台任务表；Tauri 与 server 都有真实 spawn 分支，共用 `management::runtime::management_loop()`。
- 每 30 秒重读已保存规范，按保存的时区计算当天最近应执行时点；只补当天最近一次，不积压重放往日任务。默认新规范仍停用。
- 当前支持 UTC/Etc/UTC、Asia/Shanghai；cron 只支持每日规则，分钟和小时可为整数、逗号列表、`*`、`*/N`，后三字段必须为 `*`。不支持的时区/表达式拒绝保存，已有非法配置显示错误，不静默按本机时区运行。
- v5 新增 `task_schedule_slots`，以 `(scope, task_id, due_at_ms)` 唯一约束去重。时点登记与 run 创建同一事务；同一时点在运行结束后也不能再次派发。已有活跃 run 时将该时点关联到既有 run，不另开执行。
- 执行入口在事务内再次检查计划开关和时点与当前表达式是否匹配，阻止已停用或旧配置时点的派发。
- 固定集合继续使用保存的账号列表；动态范围在触发时读取。平台动作仍使用 `OfflineTaskActionHandler`，结果为 `unsupported`，成功计数为零。
- 规范投影补上最近执行/下次计划时间；任务弹窗展示时区与时间，不将“排程已启用”写成“平台动作已接入”。配置编辑完整界面仍属 W07。

### 中断记录恢复

- v5 新增 `task_run_leases`：创建 run/重试时登记 owner 与租约，执行期间心跳续期，正常结算后移除。
- 启动及后续 tick 只恢复租约过期且没有有效账号锁的活跃 run，不按开始时间直接推断进程退出。
- 在途写操作变为 `pending_confirmation`，未开始项变为可手动重试的 `failed/interrupted_before_start`，只读同步中断变为 `failed/interrupted_read`；已确认项保持不变。
- 恢复与锁回收同一事务；重复恢复不改变已分类结果，不自动重放写请求。仍有在途执行者的 run 不允许并发重试。
- 无租约的旧版本 run 保留供手动核实，不伪造安全恢复。恢复有最长一个租约周期的等待；尚不包含供应商只读到账复查和自动继续未开始任务。

排程时点去重只证明本地派发幂等，不等于供应商活动周期幂等；真实平台接入前仍须核实活动周期与旧自动任务的竞争。
