## 七、执行过程中的两个坑（已规避，记入备忘）

### 1. 删除目录会被回收站包装拦截

本工作区 `rm` / `mv` 目录走 `genie-trash`（回收站 API）。**整树一次移入会失败**：

```
Error during a trash operation: Unknown { description: "Some operations were aborted" }
```

表层症状是 `mv: Permission denied`，**且无占用时同样如此** —— 容易误判成文件锁。特征：`cp -r` 能成功、改名失败。

**绕法**：自底向上 —— 先删子项，再 `rmdir`。

### 2. 两个目录确实被活句柄占用

`.qa-logs/iso-home`、`.qa-tmp/dist-stale-qa` 由临时起停的 `buddy-switch-rust.exe`（PID 9948）持有。首次删除失败，**数分钟后重试即成功**。

> 注：`find ... -depth -exec rm -rf {} +` 在这种场景下极慢（每个文件 spawn 一次包装进程），会被超时打断，不要使用。
